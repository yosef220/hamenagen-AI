# אפיון תוכנה — נגן מוזיקה קהילתי חכם

**סטטוס:** טיוטה ראשונה לעריכה
**גרסה:** 0.1
**פלטפורמה:** Windows (בלבד, בשלב זה)
**סוג:** קובץ הפעלה בודד (EXE) — עדיף **נייד (Portable)**, ללא צורך בהתקנה קלאסית

> שם המוצר עדיין לא נקבע — מסומן בהמשך כ־**"התוכנה"** / **[שם זמני]**.
> בסבב הבנייה הראשון נבחר שם עבודה זמני: **"המנגן"**.

---

## 1. מטרה

תוכנה עצמאית שרצה על המחשב המקומי ומאפשרת השמעת שירים מכל מאגר השירים שקיים במחשב, תוך שימוש בבקשות בשפה טבעית ("תשמיע לי שירים של שבת"). כשהמחשב מחובר לרשת, התוכנה משמשת גם להשלמת שירים חסרים (חיפוש/השמעה/הורדה) ולקבלת עדכונים. התוכנה מיועדת לשימוש קהילתי/ארגוני, מותקנת בנפרד על כל מחשב, ופתוחה לכל משתמש ללא הזדהות.

---

## 2. סקירה כללית

התוכנה בנויה משלושה כובעים עיקריים:

1. **נגן מקומי חכם** — סורק את כל השירים במחשב, מבין בקשות בשפה טבעית, ומרכיב רשימות השמעה לפי נושא, לפי תאריך הורדה, לפי תאריך יציאה ועוד.
2. **מנוע השלמה מקוון** — כשהשיר לא קיים מקומית והמחשב מחובר לרשת, מציע לחפש/להשמיע/להוריד ממקור חיצוני (כרגע יוטיוב).
3. **שכבת עדכונים** — מעדכנת את התוכנה, את מודולי ה-AI ואת ספריות ההורדה כשיש חיבור לרשת.

עיקרון-על: **התוכנה עובדת קודם כול אופליין.** כל הרכיבים החכמים (הבנת שפה, סיווג נושאי, לוח עברי) יורדים פעם אחת ואז פועלים ללא רשת.

---

## 3. קהל יעד וסביבת הפעלה

- **קהל יעד:** קהילה/ארגון; משתמש קצה ללא ידע טכני.
- **מערכת הפעלה:** Windows (10/11 ומעלה — לאישור).
- **אופן פריסה:** התקנה/העתקה בנפרד על כל מחשב.
- **הרשאות:** פתוח לכולם, ללא משתמש וסיסמה.
- **מצב רשת:** עובד אופליין באופן מלא; מנצל רשת כשקיימת.

---

## 4. עקרונות מנחים

- **נייד ככל הניתן** — רצוי שיעבוד מתיקייה בודדת בלי התקנה מערכתית, אך יוצר **קיצור דרך בשולחן העבודה** עם **אייקון מרשים**.
- **Offline-first** — פונקציונליות הליבה אינה תלויה ברשת.
- **מקור חיצוני מתחלף (Pluggable)** — יוטיוב הוא ה"תוסף מקור" הנוכחי; הארכיטקטורה מאפשרת להחליף/להוסיף מקורות מורשים בעתיד בלי לשנות את שאר המערכת.
- **מודל קטן ומקומי** — לא נדרש מודל ענק; שילוב של מילון/תגיות מתוחזק + מודל שפה קטן מקומי (ראה סעיף 8).

## 5. ארכיטקטורה — מודולים עיקריים

| מודול | תפקיד |
|------|--------|
| **Core Player** | ניגון אודיו (ואופציונלית וידאו), תור השמעה, בקרות |
| **Library Scanner** | סריקת כל המחשב לאיתור קובצי מדיה + בניית אינדקס |
| **Metadata Index** | מסד נתונים מקומי: שם, זמר, אלבום, קטגוריות, תאריך הורדה, תאריך יציאה |
| **NLP / Intent Engine** | פענוח בקשות בשפה טבעית לפעולה + פרמטרים |
| **Topic Classifier (AI מקומי)** | סיווג שיר לנושא/מועד (שבת, חנוכה, אלול...) גם ללא מילת מפתח מפורשת |
| **Fuzzy Matcher** | התאמת שם שיר/זמר גם בכתיב שונה (רווח/קו-תחתון/סדר מילים) |
| **Hebrew Calendar** | זיהוי יום/מועד/חודש עברי להצעות אוטומטיות |
| **Online Fetcher** | חיפוש/השמעה/הורדה ממקור חיצוני (יוטיוב) |
| **Updater** | עדכון תוכנה, מודולים וספריות |
| **Settings** | ניהול העדפות המשתמש |

## 6. התקנה והפעלה ראשונה (First-Run)

### 6.1 עם חיבור לרשת
1. המשתמש מוריד ומריץ את התוכנה.
2. בהרצה הראשונה התוכנה מזהה שאין לה עדיין את המודולים/התלויות ומורידה אותם אוטומטית:
   - מודל השפה/הסיווג המקומי
   - נתוני הלוח העברי
   - ספריית ההורדה החיצונית
3. בסיום — התוכנה מוכנה לעבודה אופליין מלאה.

### 6.2 ללא חיבור לרשת (חבילה אופליין)
1. יסופק **קובץ חבילה בודד** (למשל `assets.pack`) שמכיל את כל המודולים והתלויות.
2. המשתמש **מניח את הקובץ באותה תיקייה של התוכנה**.
3. בהפעלה התוכנה מזהה את הקובץ, קוראת אותו, ומתקינה ממנו את כל הרכיבים — בלי אינטרנט.

> ראו טיוטת פורמט: [OFFLINE_PACK.md](OFFLINE_PACK.md).

## 7. פתיחת התוכנה — הצעות לפי זמן

בכל פתיחה התוכנה בודקת את **התאריך העברי הנוכחי** ומציעה תוכן מתאים:
יום שישי/שבת → שירי שבת; חנוכה → שירי חנוכה; חודש אלול → תוכן הקשור לאלול; וכן הלאה.
ההצעה מוצגת כבאנר "השמע עכשיו" ואינה מפריעה — המשתמש יכול להתעלם.

---

## 8. מנוע ההוראות בשפה טבעית (ליבת המערכת)

המשתמש כותב בקשה חופשית בעברית; המנוע מפרק אותה ל**כוונה (Intent)** + **פרמטרים**.

### 8.1 סוגי בקשות
| דוגמה | כוונה | תוצאה |
|-------|-------|-------|
| "תשמיע לי שירים של שבת" | סינון לפי נושא | כל שיר שמסווג כשבת |
| "תשמיע את השירים האחרונים שהורדתי" | מיון לפי תאריך הורדה | מהחדש לישן |
| "תשמיע את השירים האחרונים שיצאו" | מיון לפי תאריך יציאה | לפי תאריך יציאה |
| "תשמיע אמת של שמוליק סוכות" | חיפוש שיר ספציפי | התאמה חכמה גם בכתיב שונה |

### 8.2 סיווג נושאי — מודול AI מקומי
גישה **היברידית**: (1) מילון תגיות מתוחזק; (2) מודל הטמעה (Embeddings) קטן מקומי
לשירים שאינם במילון; (3) שילוב — קודם המילון, ואם אין התאמה נופלים למודל.

### 8.3 התאמה חכמה לשם שיר (Fuzzy Matching)
נרמול טקסט, חיפוש רב-שדות, התאמת אסימונים, סובלנות לשגיאות כתיב ודירוג תוצאות.
